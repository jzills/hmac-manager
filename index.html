HmacManager Helm repository

Istio ambient-mode ext-authz service for HMAC request authentication.

Install from this repository (HTTP)

helm repo add zills https://jzills.github.io/hmac-manager
helm repo update
helm install hmac-manager zills/hmac-manager \
  --namespace hmac-system --create-namespace \
  --set "policies[0].name=my-policy" \
  --set "policies[0].publicKey=00000000-0000-0000-0000-000000000001" \
  --set "policies[0].privateKeySecret.name=my-hmac-secrets" \
  --set "policies[0].privateKeySecret.key=my-policy-privateKey"

At least one policy is required. See the chart documentation for the full values reference and how to enable enforcement.

Or pull the chart from GHCR (OCI)

helm install hmac-manager oci://ghcr.io/jzills/charts/hmac-manager --version 0.1.0 \
  --namespace hmac-system --create-namespace \
  --set "policies[0].name=my-policy" \
  --set "policies[0].publicKey=00000000-0000-0000-0000-000000000001" \
  --set "policies[0].privateKeySecret.name=my-hmac-secrets" \
  --set "policies[0].privateKeySecret.key=my-policy-privateKey"

Run the container directly

docker pull zills/hmac-manager:latest
