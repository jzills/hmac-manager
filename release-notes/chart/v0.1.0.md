The chart now runs its own Redis, so replay protection holds across replicas without anything to provision.

- **Redis included:** With `redis.enabled`, the default, the chart deploys a small `redis:7-alpine` instance, and every policy uses the distributed nonce cache.
- **Without Redis:** Set `redis.enabled` to false to use the in-process cache; the chart then refuses a `replicaCount` above 1, since replicas would not share nonces.
