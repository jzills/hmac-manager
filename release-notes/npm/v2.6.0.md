The client now refuses a scheme that doesn't exist, as the library does. These notes cover everything since v2.5.0, including v2.5.1 and v2.5.3, which had no tag.

- **Unknown schemes:** Creating a manager with a scheme the policy doesn't have now returns null instead of a manager that signs without it.
- **Blank schemes:** An empty or whitespace scheme name counts as no scheme, as in .NET.
- **Types:** The published TypeScript declarations match the exports.
