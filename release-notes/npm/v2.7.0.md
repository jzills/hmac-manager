A Node service can now verify signed requests itself, not only send them.

- **Verification:** The `verify` method checks a signed request the same way `VerifyAsync` does in .NET, and reports each rejection reason separately instead of throwing.
- **Replay protection:** An in-process `NonceStore` refuses a nonce it has already seen, and you can supply your own store.
- **Uppercase nonces:** A nonce sent in uppercase by another signer now verifies, since the client compares it in lowercase as .NET does.
