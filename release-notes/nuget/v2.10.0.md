Three fixes that make a request signed in .NET verify everywhere else.

- **Internationalized hosts:** A host such as `bücher.example` is signed in its punycode form, which is what travels in the `Host` header and what the npm client signs.
- **Padded header values:** Scheme header values are trimmed before they are signed.
- **Empty bodies:** A request with an empty `StringContent` body no longer adds a content hash that no verifier reproduces.

**After upgrading:** If you sign requests to an internationalized host, upgrade the signer and the verifier together: the signature for those requests changes.
