You can now check the keys on a request yourself and decide exactly what gets signed.

- **A key check of your own:** The new `OnValidateKeys` event runs before verification, so you can refuse a request by its public key.
- **Your own signing content:** A policy can build its own signing content with `UseSigningContentBuilder`, which gives you full control over what is signed and verified.
- **Events with configuration:** An `AddHmac` overload takes an `IConfigurationSection` and an `HmacEvents` together.
