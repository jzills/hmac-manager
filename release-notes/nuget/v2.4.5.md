A patch for signed requests whose body was left out of the hash.

- **POST bodies:** A body sent with chunked transfer encoding, which `PostAsJsonAsync` uses by default, is now included in the content hash.
- **Bodies in the npm client:** The client reads a clone of the request, so hashing the body no longer consumes it.
- **One dependency:** The package now depends only on `System.Runtime.Caching`.
