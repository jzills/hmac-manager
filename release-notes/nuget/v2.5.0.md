Policies can now be built per request, the headers lose their `X-` prefix, and events run asynchronously.

- **Scoped policies:** Call `EnableScopedPolicies()` to build the `IHmacPolicyCollection` per request from the `IServiceProvider`, for policies that live in a database.
- **One header:** The `EnableConsolidatedHeaders()` option combines the generated headers into a single Base64-encoded header.
- **Earlier errors:** Signing and verification throw specific exceptions, such as `HmacPolicyNotFoundException`, as soon as something is wrong.
- **Your own signing content in the client:** The npm client supports user-defined signing content too.

**Breaking:** If you handle `HmacEvents`, make each handler asynchronous. If a signer or verifier runs an earlier version, upgrade both together, since the header names changed.
