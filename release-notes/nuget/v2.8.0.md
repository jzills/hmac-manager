The library now explains itself in your logs.

- **Why a request failed:** Every rejection writes a structured log entry that says which check failed, such as an expired request, a replayed nonce or a signature mismatch.
- **Stable event ids:** Each message has an id you can alert on, listed on the [log events page](https://j.zills.io/hmac-manager/docs/reference/log-events/).
- **Loggers are optional:** Every public type keeps its existing constructor, and dependency injection supplies a logger without any change to your code.
