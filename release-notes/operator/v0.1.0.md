The first release of the operator, which makes HMAC policies Kubernetes resources.

- **Policies as resources:** You define an `HmacPolicy` (`hmac-manager.io/v1alpha1`), and the operator turns it into the configuration and Secret the ext-authz service reloads.
- **What kubectl shows:** Running `kubectl get hmacpolicies` lists them, and each one's `status` says whether it was applied or why not.
