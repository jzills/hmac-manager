The first release of `HmacManager.StackExchangeRedis`, a nonce cache that claims each nonce in Redis atomically, so replay protection holds across every instance of your app.

- **One call:** Call `AddStackExchangeRedisNonceCache` to put the Redis cache behind the `Distributed` cache type, with no change to your policies.
- **Atomic claims:** Each claim is one `SET NX`, so two instances can't both accept the same nonce.
- **Fails closed:** When Redis can't be reached, the request fails rather than being accepted without replay protection, and concurrent requests share one connection attempt.
- **Keys that carry over:** Set `InstanceName` to match the `RedisCache` you used before, and nonces it recorded stay claimed.
